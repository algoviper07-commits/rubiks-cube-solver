# Rubik's Cube Solver

A Rubik's Cube solver built from scratch in **C** using search algorithms, with plans to integrate computer vision and a web interface.

## About the Project

This project is my final project for **CS50x**. My goal is to build a Rubik's Cube solver from scratch while learning the underlying algorithms and theory instead of relying on existing libraries.

## Project Goals

* Simulate all valid cube moves
* Generate random scrambles
* Determine whether a cube state is solvable or unsolvable
* Solve the cube using search algorithms

## What I Hope to Learn

* How to plan and complete a large software project
* Data structures and algorithm design
* Rubik's Cube theory and solving algorithms
* Deeper understanding of the C programming language
* Problem-solving and software design
